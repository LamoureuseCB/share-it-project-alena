**ShareIt** - это веб-приложение, реализованное на основе принципов экономики совместного использования и предоставляющее платформу для удобного шеринга вещей между пользователями.

**Он позволяет:**
*   Пользователям рассказывать, какими вещами они готовы поделиться.
*   Находить нужную вещь и брать её в аренду.
*   Бронировать вещь на определённые даты, закрывая доступ для других пользователей.
*   Оставлять запросы на отсутствующие в сервисе вещи.
*   Оставлять отзывы на вещи после использования.

**Архитектура приложения:**
*   **Gateway** – валидация входящих запросов.
*   **Server** – обработка бизнес-логики.
*   **PostgreSQL** – хранилище данных.

Каждый компонент разворачивается в отдельном **Docker-контейнере**.
Приложение включает **юнит и интеграционные тесты**, обеспечивая проверку ключевых компонентов.


**Технологический стек:**
*   **Backend:** Java, Spring Boot
*   **Database:** PostgreSQL, JPA/Hibernate
*   **Maven**
*   **Lombok**
*   **Docker & Docker Compose**
*   **JUnit & Mockito**
